# 扩充毛选卡片至150条

## Goal

将应用内可发布、可离线阅读的正式卡片从 31 条扩充到 150 条，增加内容覆盖面，同时保持现有内容包的事实核验、来源记录和阅读字段质量。

## Confirmed Facts

- 当前 `content/` 通过正式校验，共有 31 条 `published` 卡片、0 条下架记录、8 张背景图；文件名为 `000-development-placeholder.yaml` 的卡片也已正式发布并计入 31 条。
- 达到 150 条正式卡片需新增 119 条，而不是 120 条。
- 根目录 `资料/` 提供 51 条候选，包含毛泽东著作 24 条、毛泽东诗词 10 条、鲁迅与红色经典 17 条；其中约 8 条已经进入现有正式内容，其余候选不足以单独完成增量。
- 所有现有正式卡片均为毛泽东著作内容。
- 作者范围已确定为毛泽东作品，可包含《毛泽东选集》第一至四卷、其他可核验著作和毛泽东诗词；不纳入鲁迅及其他红色经典作者。
- 内容采用一张卡片一个 UTF-8 YAML 文件，通过 Python 内容工具构建完整快照并同步到 Android 内置 `bootstrap.zip`。
- 正式卡片必须使用稳定 UUID、连续且不超过 90 个 Unicode code point 的原文、至少两个不同域名的来源，并包含启示、解读、历史事件、背景、故事和已核验状态。

## Requirements

- 正式发布卡片总数精确为 150 条，保留现有 31 条卡片的 ID、修订号和内容。
- 新增内容不得用重复短句、同义改写、拼接摘句或错误归因凑数。
- 选材优先公众辨识度高、传播广、经权威媒体、党史资料、教材或公开讲话反复引用的经典原句；不能仅因容易凑齐字段而收录冷僻句子。
- 允许同一篇作品收录多条语义独立的经典句子：普通作品最多 3 条，少数公认名篇最多 5 条；不得把同一连续句拆成多张卡片，也不得收录近重复表达凑数。
- 每条新增卡片都需能定位到具体作品、卷次或文集、写作日期，并有至少一个原文或权威来源及另一个独立域名来源。
- 解读须回到原文语境，明确适用边界，不把现代概念强行解释为作者原意。
- 复用现有 8 张原创背景图，不因扩充卡片数量新增图片资产。
- 新增内容按 89 条著作或讲话名句、30 条诗词名句组织，使最终 150 条内容约为 120 条著作或讲话、30 条诗词。
- 将内容版本升级到 `1.4.0`，更新发布日期、发布说明、声明数量和 APK 内置内容包；内容 schema 保持不变。
- 将 Android 应用升级到 `versionName=1.4.0`、`versionCode=5`，通过既有 GitHub Actions 正式签名并发布可覆盖升级的 APK。
