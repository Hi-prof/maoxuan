# 星火摘读 MVP

## Goal

为个人阅读打造一款 Android 端《毛泽东选集》名言卡片应用：用户可以像刷短视频一样连续阅读名言，并进一步了解原文出处、时代背景与相关故事；内容通过静态内容源持续更新，无需每次增加内容都发布新版 App。

## Target User And Value

- 首要用户是应用所有者本人，产品优先服务于日常阅读、理解与回顾，而非社交传播。
- 用短卡片降低开始阅读《毛泽东选集》的门槛，同时保留可追溯的出处与上下文，避免名言脱离原文。

## Confirmed Facts

- 应用正式名称为“星火摘读”，用于桌面图标名称、系统任务列表和应用内品牌位置。
- 桌面图标采用暖白底、深红色星火与展开书页的简洁图形，并按 Android 自适应图标规范制作前景与背景层。
- MVP 选择个人版，仅服务应用所有者本人，不提供账号、注册或跨设备同步。
- MVP 采用本地优先模式：已同步的名言、点赞、收藏和阅读状态都保存在 Android 本地，日常阅读不依赖远端服务在线。
- 内容维护采用结构化文件加校验/发布脚本，不开发 Web 管理后台；远端只承担从内容源到 Android 的单向内容更新。
- 内容分发采用 GitHub Releases 公开静态地址：发布版本清单、内容文件和图片，不运行常驻 API 服务；App 仅在检查更新时联网。
- Android 源码、YAML 内容源、来源记录、自动化工作流及公开 Releases 使用同一个公开 GitHub 仓库；仓库不包含任何手机端个人数据。
- 内容更新完全由用户手动触发；App 启动时和系统后台均不自动检查或下载更新。
- 检查到新内容版本后，App 先展示版本号、发布日期、预计下载大小及新增、修改、下架数量；只有用户再次确认才下载和应用。
- 首批内容由公开网络资料整理，不直接采用语录聚合站；每条内容必须经过可追溯来源的交叉核验。
- 内容范围以《毛泽东选集》为核心，同时允许收录《毛泽东文集》及可核验的正式讲话；不同文献系列必须准确区分和标注。
- MVP 首批发布 30 张经过完整核验的正式卡片，后续通过静态内容包持续追加。
- 首批 30 张卡片及其背景图片随 APK 内置；首次安装无需联网即可阅读，GitHub Releases 仅负责后续内容更新。
- 首批 30 张按主题均衡原则选取，以《毛泽东选集》为主，尽量覆盖不同卷次及实践、学习、调查研究、群众、方法论、奋斗、建设等主题；其他正式文献仅作少量补充。
- 每张正式卡片都必须配置一张背景图片，图片允许在多张卡片之间复用，但应尽量匹配内容主题或时代。
- 卡片视觉方向已确认：以 `reference-card-system-v6` 为设计基线，大字号语录为主体，人物或历史影像仅作低对比度背景水印，点赞、收藏和背景入口位于卡片之外。
- MVP 固定使用浅色主题，不跟随 Android 系统深色模式，也不制作深色卡片变体。
- 背景故事交互已确认采用卡片翻面：正面展示名言，点击“读背景”或向左/向右横滑均可翻到背面；背面允许滚动长内容，可通过再次点击、明确的返回操作或横滑翻回正面。
- 卡片解读采用离线预编写内容，不调用 AI 或远端接口；每张活动卡片都必须提供“核心意思、理解重点、现实启示”三个独立部分。
- “解读”入口位于卡片外操作区的“读背景”左侧，并同时出现在主阅读页及从收藏、点赞、搜索进入的完整卡片详情页。
- 点击“解读”后使用可滚动的底部弹层展示当前卡片解读；弹层关闭后保留原卡片、阅读位置和正反面状态。
- 客户端目标平台为 Android，最低支持 Android 9（API 28）。
- 核心阅读交互为类似短视频的纵向逐条滑动，一屏聚焦一条内容。
- 主阅读流采用未读优先的随机顺序：同一阅读轮次内不重复展示，全部读完后再开始新一轮；同步新增内容进入当前未读集合。
- 当前轮次完成后展示独立完成状态，不自动进入下一轮；用户明确点击“开始新一轮”后，才重新生成随机阅读顺序。
- 当前卡片完整显示并在前台连续停留满 3 秒后计为当前轮次已读；正面和背面的停留时间均计入，快速划过不计入。
- 当前轮次允许双向浏览：向上滑进入下一张，向下滑可连续返回本轮历史卡片；主动回看不撤销已读状态，也不视为系统重复推荐。
- 每条正式内容必须包含名言正文和准确出处；时代背景、原文上下文与相关故事均为选填，仅在有可靠资料时提供。
- 名言正文最多约 90 个汉字（标点计入、出处不计），必须选取语义完整的连续原文，不得改写、拼接或用省略号掩盖删节。
- 用户需要点赞与收藏；两种状态保持独立，但在同一个“收藏与点赞”一级页面中通过分段控件切换查看。
- MVP 支持把当前名言生成图片，并通过 Android 系统分享面板发送到其他应用；分享入口与点赞、收藏、“读背景”一样位于卡片之外。
- 分享图固定为约 1080×1440 的 3:4 竖版，沿用浅色实体卡片、大字号名言和低对比度背景图，包含篇名、准确出处及小号“星火摘读”标识。
- MVP 使用“阅读 / 收藏 / 笔记 / 我的”四栏底部导航；“收藏”页集中展示收藏与点赞，“我的”提供内容版本、上次更新时间和手动检查更新入口。
- 收藏与点赞内容均采用纵向摘要列表：展示背景缩略图、两至三行名言预览、篇名和内容状态；点击后进入可翻面的完整卡片详情。
- MVP 提供完全本地的个人笔记：既可创建不关联卡片的独立笔记，也可从卡片操作区直接创建关联当前卡片的笔记；同一卡片允许关联多篇笔记。
- 每篇笔记保存可选标题、非空正文、可选卡片关联、创建时间和最后修改时间；笔记不进入内容包，也不上传网络。
- MVP 提供简单本地搜索，从阅读页顶部的搜索入口进入，仅匹配名言正文和篇名；搜索结果采用摘要列表并可打开完整卡片。
- 搜索历史在用户提交搜索时写入本地并跨应用重启保留；最多保存最近 10 条，相同关键词去重后移到最前。
- 内容由静态内容源统一发布，Android 客户端支持按内容包版本同步。
- 远端下架的卡片不再进入主阅读流；若本机已点赞、收藏或存在关联笔记，则在“收藏”页或“笔记”页保留最后一次成功同步的内容，并明确标记“已下架”。
- 视觉质量是首要要求之一，整体应体现庄重、克制的红色文化气质，而不是廉价的满屏大红。

## Requirements

### MVP Product Scope

- 应用无需登录即可使用，MVP 的静态内容源使用 GitHub Releases 只读公开地址。
- 提供纵向沉浸式卡片阅读流。
- 在本地保存当前阅读轮次和已读集合；重启 App 后继续当前轮次，不重新随机已读内容。
- 本地同时保存当前轮次的稳定随机顺序和当前位置，重启后仍可从当前位置前后浏览同一顺序。
- 轮次完成页展示本轮已读卡片数量，以及本轮卡片中当前已点赞和已收藏的数量，并提供“开始新一轮”主操作。
- 已读计时仅在该卡片是完整显示的当前页且 App 位于前台时进行；翻面不重置计时，切换卡片或进入后台时停止当前连续计时。
- 提供名言正文与出处的分层阅读体验，并按实际内容展示可选的时代背景、原文上下文和相关故事。
- 卡片翻到背面后应优先处理背面内容滚动，避免与主阅读流的纵向换卡手势冲突。
- 横滑翻面必须跟随手指呈现连续的 3D 透视进度；拖动不足阈值时自然回弹，超过阈值或快速甩动时完成翻面，且不能误触发纵向换卡或背面纵向滚动。
- 主阅读页和完整卡片详情页都应提供“解读”操作；它固定显示在“读背景”左侧，在卡片正面或背面均可打开。
- 解读底部弹层按“核心意思、理解重点、现实启示”分区展示，支持长内容滚动，并可通过关闭按钮、遮罩、下滑或系统返回键退出。
- 打开或关闭解读不得改变当前卡片、正反面、点赞收藏状态或主阅读页位置；弹层打开期间不得误触发纵向换卡。
- 支持点赞、取消点赞、收藏、取消收藏。
- 支持新增、编辑和删除个人笔记；空白正文不得保存，删除前必须二次确认，有未保存修改时返回必须提示用户确认是否放弃。
- 支持在本地生成固定版式的分享图片并调用系统分享面板，不依赖远端图片生成服务。
- 分享图不得包含状态栏、导航栏、操作按钮、背景故事或参考来源 URL，且不同手机尺寸生成的图片版式与像素尺寸保持一致。
- 点赞、收藏及相关个人状态仅在 Android 本地持久化，卸载应用后可丢失。
- 提供独立“收藏”页面，并使用“收藏 / 点赞”分段控件查看对应内容及进入卡片详情；切换分段后保留各自列表位置。
- 提供独立“笔记”页面，按最后修改时间倒序展示笔记；关联卡片的笔记显示名言摘要、篇名和下架状态，并可进入卡片详情。
- “我的”页面提供当前内容版本、上次更新时间和“检查更新”操作，不再承载点赞列表。
- 从收藏或点赞列表进入详情再返回时，应恢复原列表位置；在一级页面间切换时，应保留主阅读页当前卡片。
- 从卡片操作区创建笔记时自动关联当前卡片；从“笔记”页创建时生成独立笔记。点击现有笔记进入编辑页并保留原关联关系。
- 搜索使用已同步到本机的内容，无需联网；不提供背景全文搜索、模糊语义搜索或高级筛选。
- 搜索框为空时展示最近搜索历史；点击历史记录可回填关键词，每条记录支持单独删除，并支持一次清空全部记录。
- 输入过程、点击历史记录或仅打开搜索结果都不新增历史；只有用户通过输入法搜索操作提交非空关键词时才保存。
- 支持静态内容源新增、修改、下架后的客户端同步。
- 下架卡片若仍有本机点赞、收藏或关联笔记，应保留可离线查看的内容快照；取消最后一个点赞/收藏状态并删除最后一篇关联笔记后，才可移除该下架内容的本地快照。
- 内容维护者可以通过结构化文件新增、修改或下架卡片，并在校验通过后发布新的内容版本。
- 内容维护源采用“一张卡片一个 UTF-8 YAML 文件”，配套固定模板；图片独立存放并由卡片文件引用。
- 内容发布由 `content-vX.Y.Z` 版本标签显式触发；普通代码或内容提交不得自动对客户端发布。
- 客户端应缓存已同步内容，在无网络时仍能阅读已有卡片。
- 内容更新过程应展示明确的检查、可更新、下载、校验、成功和失败状态；用户取消下载或更新失败时继续使用原内容版本。
- 首次启动时应从 APK 内置内容初始化本地内容库，不得把首次联网下载作为进入阅读页的前置条件。

### Content Integrity

- 每条名言使用稳定且不可复用的唯一标识。
- 内容应保留原文出处信息；不能确认出处的文本不得伪装成已核实名言。
- 原文上下文、时代背景与相关故事应和名言正文分字段保存，便于独立修订与按需展示；选填字段缺失时界面不得显示空栏目。
- 每张活动卡片必须以结构化 `interpretation` 字段保存 `coreMeaning`、`keyPoint`、`contemporaryRelevance`；三个子字段去除首尾空白后均不得为空。
- 单张卡片的三段解读合计以约 200～300 个汉字为目标，规范化后硬上限为 600 个 Unicode code point；内容须依据已核验原文与现有背景材料，不虚构作者意图或新增未经核验的历史事实。
- 新增或修订解读属于正式内容变化，必须提升卡片 `revision`；首批全部活动卡片及 APK 内置内容包必须同时补齐解读。
- 每条内容应保存来源 URL、访问日期和核验状态；正式内容至少使用两个相互独立的来源核验，其中至少一个应能追溯到完整原文或权威出版信息。
- 卡片背面底部提供默认收起的“参考来源”，展开后显示来源名称和访问日期；联网时可调用系统浏览器打开来源 URL，离线时仍显示已保存的来源信息。
- 每条内容必须分别记录文献系列、卷次、篇名和写作/讲话时间；来自《毛泽东文集》或其他正式讲话的内容不得笼统标注为“出自《毛泽东选集》”。
- 每张图片必须记录来源 URL、许可或公版依据和必要的作者信息；无法确认使用边界的图片不得进入正式内容包。
- 所有正式卡片的背景图片都必须具备允许在 App 内展示并随分享图复制、再分发的许可或公版依据；不满足条件的图片不得进入正式内容包。
- 静态内容包只收录实现卡片阅读所需的适量引文和原创背景说明，不镜像或重新发布完整著作全文。

### Experience Constraints

- 主阅读页面以内容为中心，操作按钮不能遮挡正文。
- 长短不同的正文与背景内容都必须可完整阅读，不能溢出或被截断。
- 内容同步失败不能阻断本地已缓存内容的阅读。
- 在最小 `360 x 640 dp` 视口中，新增“解读”后卡片操作栏仍不得溢出、换行遮挡或压缩卡片正文；弹层标题、关闭入口和三个正文区块均须可达。
- 视觉参考已明确为实体语录卡片：浅色卡面、大面积留白、克制的红灰文字、底部人物或历史照片、轻微纸张质感和较小圆角。
- 语录文字必须是卡片的绝对视觉主体，占据更大的面积和视觉权重；人物或历史照片只能作为低对比度背景水印，不能形成独立的大幅插图区。
- 默认语录排版应呈现接近标题文字的醒目尺度，而不是普通正文尺度；仅在长文本无法完整容纳时按预设档位缩小字号与行距。
- 内容校验和卡片排版应共同保证约 90 个汉字以内的正文无需滚动即可完整显示；正面不得通过无限缩小字体容纳超长内容。
- 卡片应轻、静、亲近，避免历史杂志、政治海报、满版大红、粗重黑框、手机模型和仿古装饰拼贴。
- 固定浅色主题仍需控制页面亮度与对比度，确保夜间阅读不刺眼；系统切换深色模式时界面不得出现错误反色或不可读控件。
- 早期已被否决并删除的杂志、海报、仿古等视觉稿不作为后续设计依据；最终仍采用已确认的浅色实体卡片视觉和卡片翻面交互。

## Acceptance Criteria

- [ ] Android 用户可以纵向滑动浏览服务端发布的卡片，一次聚焦一条。
- [ ] 安装后的桌面名称、系统任务名称及应用内品牌文字统一使用“星火摘读”。
- [ ] 桌面图标在 Android 支持的圆形、方形和圆角方形遮罩下均保持主体完整，小尺寸下仍可识别星火与书页，不使用人物照片或仿古印章效果。
- [ ] 同一阅读轮次中不会重复展示已读卡片；退出并重新打开 App 后仍继续当前轮次。
- [ ] 用户可向下连续返回当前轮次中看过的卡片，再向上回到原位置；主动回看不改变已读、点赞或收藏状态。
- [ ] 当前卡片连续停留满 3 秒后持久化为已读；不足 3 秒快速划过、切到其他页面或进入后台时不会误记为已读。
- [ ] 当前轮次全部读完后先展示完成页；只有用户点击“开始新一轮”才生成新的随机顺序，点赞与收藏状态不受影响。
- [ ] 轮次完成页准确展示本轮已读、已点赞和已收藏数量。
- [ ] 用户可以从卡片正面点击操作或向左/向右横滑触发翻面，在背面查看必填出处，以及内容中实际提供的原文上下文、时代背景或相关故事，并通过点击操作或横滑可靠返回正面。
- [ ] 横滑时卡片按拖动距离连续呈现有透视感的 3D 翻面；短拖会平滑回弹，过阈值或快速甩动会平滑完成，动画期间没有内容镜像、闪切或明显跳帧。
- [ ] 背面内容超过一屏时可以完整滚动阅读，滚动期间不会误切换到上一张或下一张卡片。
- [ ] 主阅读页和完整卡片详情页均在“读背景”左侧显示“解读”；从正面或背面点击后都能打开当前卡片的解读弹层。
