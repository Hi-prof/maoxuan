# 按书籍筛选阅读内容

## Goal

让用户在现有“兴趣偏好”设置中按内容书籍/系列选择阅读范围，例如只阅读《毛泽东选集》，并让主阅读流只出现所选范围内的卡片。

## Confirmed Facts

- 正式内容已经通过卡片的稳定 `series` 字段分为 `毛泽东选集`、`毛泽东诗词`、`名人名言`、`马原思考` 四类。
- 当前兴趣偏好只影响推荐排序，不会排除未选内容。
- 阅读流使用持久化阅读轮次；偏好保存后必须保留仍符合筛选条件的阅读进度，并移除不符合条件的轮次条目。
- 书籍偏好是本地个人数据，不应上传或写入内容包。

## Requirements

- 在现有兴趣偏好页面增加清晰独立的“内容范围”选择区域。
- 支持从当前已安装内容动态提供可选书籍/系列，并持久化多个所选稳定值。
- 提供明确的“全部内容”选项；选中时不限制系列，选择具体系列时至少保留一项。
- 保存偏好后立即重排当前阅读轮次，仅保留所选书籍/系列中的有效卡片。
- 书籍筛选仅约束主阅读流；搜索、收藏、点赞和笔记继续显示全部有效个人内容。
- 内容更新引入新的书籍/系列时，应自动出现在设置选项中，但不能绕过已有筛选进入阅读流。
- 保留点赞、收藏、笔记、兴趣标签及“减少此类”反馈等既有个人数据。
- 对旧数据库执行无损 Room 迁移，迁移后默认不限制内容。

## Acceptance Criteria

- [x] 用户可以在“兴趣偏好”中同时调整兴趣标签和内容范围，并一次保存。
- [x] 只选 `毛泽东选集` 后，主阅读流每张卡片的 `series` 都是 `毛泽东选集`。
- [x] 选择多个系列时，主阅读流只包含这些系列；选择“全部内容”时恢复全部系列。
- [x] 保存筛选后当前卡片若仍符合条件则保持定位，否则定位到最近的符合条件卡片。
- [x] 新建阅读轮次和内容更新后的轮次重排都遵守保存的筛选。
- [x] App 重启后筛选仍然生效；旧用户升级后默认继续看到全部内容。
- [x] 数据库迁移、Repository 筛选、设置界面交互和关键阅读流程均有自动化测试。

## Out Of Scope

- 不修改内容包结构或批量重写正式内容卡片。
- 不增加远端账号同步。
- 不把书籍偏好作为推荐权重；它是候选内容的硬筛选条件。
