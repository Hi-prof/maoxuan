# 赤印文摘视觉优化设计

## 1. Scope

本任务统一优化阅读主卡片、搜索结果、收藏和点赞页面。业务行为、搜索算法、收藏/点赞持久化、翻卡手势、阅读轮次和导航均保持不变。

实现包含四个互相依赖的部分：

1. 使用可核验授权的历史档案照片替换主卡片的抽象线稿背景。
2. 将已存储的图片来源与许可信息投影到领域模型、背景页和分享流程。
3. 将搜索、收藏和点赞统一为无缩略图的“赤印文摘”摘要列表。
4. 调整搜索框、结果数量和收藏/点赞分段控件的层级与间距。

## 2. Visual System

保留现有 `Ink #272522`、`MutedInk #6E6962`、`SpiritRed #A52A2E`、`Paper #F8F6F0`、`Canvas #F0F0ED` 和 `Divider #D9D7D1`，新增仅用于系列索引的 `ArchiveGreen #58665C`。不使用渐变、仿古纸纹、装饰圆球、重黑边框、嵌套卡片或全屏红色。

名言继续使用内置 Noto Serif SC；界面与元数据继续使用系统无衬线字体。所有文字 `letterSpacing = 0.sp`，字体不随视口宽度缩放。

## 3. Reader Card

- 卡片维持 `8.dp` 圆角、`2.dp` 稳定阴影和现有翻转/滚动合同。
- 历史照片全幅裁切，运行时降至低饱和，并以统一纸白蒙层控制到约 14%–18% 的可见强度。
- 素材预处理为竖版构图，关键主体避开名言和底部出处区域；不对图片使用模糊滤镜。
- 正常高度卡片在名言上方显示短系列索引；紧凑高度隐藏该索引，优先保证 90 字名言和出处不重叠。
- 图片缺失时只显示纸白背景，不显示占位容器。

## 4. Summary List

`CardSummaryList` 仍是搜索、收藏和点赞唯一共享的摘要组件，但删除图片和逐项外框。每项由索引列、朱红竖线、正文和底部分隔线组成：

```text
卷四  |  夺取全国胜利，这只是万里长征……
1949  |  《在七届二中全会上的报告》
```

- 索引列宽约 `46.dp`，朱红竖线宽 `2.dp`。
- 《毛泽东选集》显示 `卷一` 至 `卷四`；《毛泽东诗词》显示 `诗词`；其他系列显示 `马原`、`名言` 等稳定简称。
- 日期显示完整古代标签或现代年份；完整作者/卷次保留在正文元数据中。
- 名言最多三行，篇名一行，元数据一行；条目最小高度 `112.dp`，允许长内容自然增高。
- 已下架用小号朱红文字表示，不增加胶囊标签。

## 5. Search And Saved Screens

搜索输入使用 Material 3 filled text field：纸白填充、`8.dp` 圆角、透明默认指示线、聚焦时 `2.dp` 朱红底线。返回、清空和搜索图标保留 `48.dp` 点击目标。非空查询显示 `找到 N 条`，历史列表继续保留独立删除和清空操作。

收藏/点赞保留两个独立 `LazyListState`。分段控件保留至少 `48.dp` 点击高度，但最大宽度收窄并居中；收藏与点赞使用对应 Material 图标，选中态使用 `SoftRed`。列表上方显示当前分段数量。

## 6. Image Rights Data Flow

现有内容包、DTO 和 Room 已保存 `sourceUrl`、`creator`、`licenseName`、`licenseEvidence` 与 `verifiedAt`，因此不修改 schema，也不迁移数据库。

```text
image YAML
  -> ImageDto
  -> ImageAssetEntity
  -> AppRepository image map
  -> QuoteCard.imageAttribution
  -> BackgroundSheet + ShareCardRenderer
```

新增不可变领域值：

```kotlin
data class ImageAttribution(
    val creator: String,
    val sourceUrl: String,
    val licenseName: String,
    val licenseEvidence: String,
)
```

`QuoteCard.imageAttribution` 可空，以兼容缺图和测试夹具。背景页提供可点击的图片来源与许可；分享图片写入简短署名，分享 Intent 的文本同时携带完整来源和许可 URL。

## 7. Archive Photo Library

第一阶段使用 24 张左右照片，按四个系列各六个主题建立图库：

- 毛泽东选集：调查与群众、战争与军队、延安与学习、生产建设、统一与国际、胜利与城市。
- 毛泽东诗词：山岳、江河、雪原、长征道路、梅花/自然、城市与时代变化。
- 马原思考：工业、劳动者、书籍手稿、城市社会、国际运动、演讲与组织。
- 名人名言：阅读写作、舞台文学、科学探索、公共演讲、公民权利、远行与自然。

素材通过 Wikimedia Commons API 或同等可追溯机构页面获取。每张照片必须有稳定来源页、作者或机构、明确许可、许可证据链接，并允许应用内展示和分享再分发。照片不得暗示错误的人物、年代、地点或具体事件关系。

卡片仍显式保存 `imageId`。映射根据 `series + themes` 离线生成，输出确定；运行时不随机选图。所有改变 `imageId` 的已发布卡片 revision 增加 1，内容版本从 `1.5.0` 升级到 `1.6.0`。

## 8. Compatibility And Rollback

- 内容包 schema 保持 3，Room 保持版本 7，旧客户端仍能读取新图片。
- 图片全部使用新 ID，绝不以旧 ID 指向新字节。
- 回滚 UI 只需恢复 Compose 和领域投影；回滚内容需发布更高内容版本与更高卡片 revision，不能复用 `1.5.0` 或降低 revision。
- 旧 8 张抽象图片在全部卡片完成新 ID 映射后移除，确保正式内容快照不存在未引用素材；删除已获得用户明确批准。

## 9. Verification

验证 JVM、Android Lint、Debug 构建、内容工具、正式内容校验和确定性构建。Compose 仪器测试覆盖摘要索引、搜索结果数量、分段切换、图片署名、紧凑 90 字卡片和现有翻卡手势。设备截图覆盖 `360 x 640`、`360 x 800`、`412 x 915`，并检查真实照片、缺图、长作者名、古代日期和已下架状态。
