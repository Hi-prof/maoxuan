# 优化卡片手势冲突

## Goal

降低卡片翻面与纵向换卡之间的手势误判，并让读者在卡片背面阅读长内容后可以自然地切换到相邻卡片。

## Confirmed Facts

- 阅读页使用 `VerticalPager` 上下切换卡片，卡片自身使用横向拖动翻面。
- 当前两个手势识别器会同时观察同一段指针移动；横向拖动携带少量纵向分量时，外层分页仍可能开始移动。
- 卡片背面使用独立的纵向滚动；现有规范要求背面内容可完整滚动，并在到达顶部或底部后把剩余拖动交给分页器。
- 现有仪器测试只验证短背面可向下一页，尚未覆盖长背面滚到底部后的分页交接，也未覆盖带纵向偏移的横向拖动。

## Requirements

- 横向翻面与纵向换卡必须进行明确的方向仲裁；一次手势确定方向后，不得同时触发另一种动作。
- 普通上下滑动仍可在卡片正面切换上一张或下一张。
- 卡片背面的长内容必须保持可滚动、可完整阅读。
- 背面纵向手势先滚动内容；到达顶部或底部后，同一次连续拖动的剩余距离应交给分页器，以切换到相邻卡片。
- 不增加可见按钮、教学文案或新的导航控件。
- 保持现有翻面动画、无整卡点击翻面和无“返回正面”可见按钮的约束。

## Acceptance Criteria

- [x] 明显以横向为主、但带有少量纵向偏移的拖动只翻面，不切换卡片。
- [x] 明显以纵向为主、但带有少量横向偏移的拖动只切换或滚动，不翻面。
- [x] 未达到翻面距离和速度阈值的短横拖回弹到原面。
- [x] 长背面内容可以滚动到末尾，且末尾之后可以切到下一张；顶部可以切到上一张。
- [x] 背面内容在一次连续拖动中到达边缘后，无需抬手重滑即可继续带动相邻卡片。
- [x] 现有卡片布局、无障碍语义和翻面动画测试继续通过。
- [x] 新增稳定的 Compose 仪器回归，覆盖斜向手势仲裁与长背面边缘分页。

## Out of Scope

- 改变阅读页的纵向分页方向。
- 增加手势设置项或调整卡片视觉设计。
- 修改背景底部弹层的滚动和关闭交互。

## Notes

- 本任务是单一交互边界修复，按轻量任务处理，仅维护 PRD。
- 采用“方向锁定 + 背面边缘连续交接”方案，不按速度区分滚动与换卡。
