# 优化毛选卡片解读与启示

## Goal

提升《毛泽东选集》系列卡片的可读性：让读者先看懂原文在说什么，再从写作背景、历史处境或作者当时面对的问题理解这句话；启示则用平易、轻松、贴近日常的语言提供一种思考角度，而不是训诫读者。

## Confirmed Facts

- 当前内容库共有 220 张 `literature.series: 毛泽东选集` 的正式卡片，文件范围为 `000`、`002-120`、`601-700`。
- 卡片使用 schema 4，解读字段为 `interpretation.explanation`，启示字段为 `interpretation.inspiration`。
- `explanation` 上限为 420 个 Unicode code point，`inspiration` 上限为 220 个，两者合计上限为 600 个。
- 修改已发布卡片内容时必须递增该卡片的 `revision`；UUID、引文、出处和其他内容字段保持稳定，除非核查发现其直接妨碍正确解读。
- `000` 至 `030` 的多数卡片已经具备较具体的语义说明和背景解释；其余卡片中存在大量复述原句、套用主题模板或泛泛提醒“不要脱离历史”的内容。

## Requirements

- 本次只处理《毛泽东选集》系列；毛泽东诗词、热门名人名言、马原思考卡及其他系列不在范围内。
- 每条解读先用现代、自然的中文说明原句的直接意思，不照抄原句充字数。
- 每条解读结合卡片已有的篇名、日期、历史背景、上下文或作者当时面对的现实问题，说明为什么会这样说。
- 背景信息必须服务于理解原句；没有可靠依据时不虚构具体心理、现场细节、人物对话或因果关系。
- 解读区分原文在当时的含义与今天可以借鉴的方法，避免把战争、阶级斗争等特定结论生硬套进日常生活。
- 每条启示用平易、轻松、非命令式的口吻，给出贴近日常的一种观察、选择或行动角度。
- 启示不使用空泛口号、宏大说教、道德评判，也不机械重复“面对复杂局面”“保留修正空间”“清楚说明依据和边界”等模板句。
- 保留已经符合标准的高质量内容，只修改未达标的 `explanation` / `inspiration`，并仅为实际变更的卡片递增 `revision`。
- 采用逐条审阅、选择性重写方案，不按文件编号或卡片批次一刀切；已经同时满足直接释义、具体语境和自然启示要求的内容保持原样。
- 所有修改必须满足现有 YAML/schema、长度、NFC、正式卡片数量和确定性构建契约。

## Acceptance Criteria

- [x] 修改后的解读至少使用一项与该卡相关的可靠语境信息，并且不虚构作者心理或历史细节。
- [x] 修改后的启示自然、具体、克制，不讲大道理，不把特定历史结论直接当作普遍处世法则。
- [x] 未修改卡片的正文与 `revision` 保持不变；修改卡片的 `revision` 恰好递增 1。
