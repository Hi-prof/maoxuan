# 个性化卡片推荐

## Goal

当卡片数量增多后，根据用户主动选择的兴趣和本地阅读行为，优先展示更可能感兴趣的内容，同时保留内容多样性和用户控制权。

## Confirmed Facts

- 应用是本地优先的 Android 应用，当前内置 600 张卡片。
- 用户的阅读进度、点赞、收藏和笔记均保存在本地 Room 数据库。
- 当前阅读流使用持久化随机顺序，优先未读且同一轮不重复。
- 项目不包含账号、远程用户数据库或统计 SDK，个人阅读状态不离开设备。
- 用户希望首次进入时先看到一组兴趣标签，可主动选择感兴趣的内容方向。
- 现有 600 张正式卡片已携带 `themes`，共有 137 个原始主题，且分布很不均衡，不适合不经整理直接作为首次选择项。
- 内容还有四个粗粒度系列：毛泽东选集 120 张、毛泽东诗词 30 张、名人名言 300 张、马原思考 150 张。
- 现有数据能区分点赞、收藏、关联笔记和阅读完成；阅读完成的判定是卡片稳定停留 3 秒。

## Requirements

- 首次进入推荐阅读体验时，向用户展示可选的兴趣标签。
- 首次兴趣选择允许跳过；跳过后使用均衡内容流，且用户可以稍后在应用内补选。
- 首次兴趣选择只对全新安装的用户显示；已有用户升级后不弹出该页面。
- 推荐直接升级现有“阅读”内容流，不新增独立的推荐导航或第二套阅读进度。
- 现有纵向翻卡、持久化阅读轮次、未读优先、单轮不重复和回看体验必须保留。
- 用户的兴趣选择和推荐所需的个人行为数据只保存在本地。
- 首次选择使用经过策划、数量可控的兴趣大类，而不是直接展示全部原始主题。
- 首批兴趣标签应比 8 个大类更细，同时每个标签需要映射到足够的现有内容，不直接暴露稀疏的原始主题。
- 首批使用 12 个兴趣标签：自我成长、学习求知、人生智慧、理想奋斗、勇气行动、实践求真、哲学思辨、劳动创造、人际关系、人民社会、历史时代、诗词文学。
- 用户最多选择 5 个兴趣标签。
- 推荐结果不应只重复单一类内容，应保留一定的探索性和内容多样性。
- 阅读流提供“减少此类”显式反馈，用于降低当前卡片相关主题和系列的后续推荐权重，但不做永久屏蔽。
- 触发“减少此类”后应离开当前卡片，用户可以在应用内清除这类反馈。
- 推荐画像仅使用保守的显式信号：收藏和关联笔记是强正向信号，点赞是正向信号，“减少此类”是强负向信号。
- 停留满 3 秒的已读记录仅用于已读管理和去重，不作为兴趣信号；搜索关键词和快速划过暂不参与推荐画像。
- “我的”中增加“兴趣偏好”设置，新老用户都可以修改兴趣标签并清除“减少此类”反馈。
- 推荐功能不得破坏现有阅读进度、点赞、收藏、笔记和内容更新数据。
- 完成开发后将应用版本提升为 `1.8.0 / versionCode 10`，构建正式 APK，推送源码与 `app-v1.8.0` 标签，并由 GitHub Actions 发布正式 App Release。

## Acceptance Criteria

- [x] 新用户在首次进入相关阅读体验时可以选择兴趣标签。
- [x] 已有用户升级后不显示首次兴趣选择页，现有阅读数据和进入路径不受阻断。
- [x] 用户可以跳过首次兴趣选择，并在不选标签时正常进入均衡内容流。
- [x] 兴趣选择页和“我的”设置均展示确认的 12 个标签，并阻止用户同时选择超过 5 个。
- [x] 完成选择后，卡片排序会受所选兴趣影响，且仍会适量展示其他内容。
- [x] 个性化排序出现在现有“阅读”流中，不要求用户切换到另一个推荐页面。
- [x] 已有用户升级后不会丢失已有阅读和收藏等本地数据。
- [x] 新老用户都可以在“我的”中打开“兴趣偏好”，修改兴趣标签并清除负向反馈。
- [x] 用户对当前卡片选择“减少此类”后，系统记录本地负向反馈、离开当前卡，并降低相似内容的后续权重。
- [x] 收藏、点赞、关联笔记和“减少此类”会按确认的方向改变后续推荐权重。
- [x] 仅阅读、搜索或快速划过卡片不会该变兴趣权重。
- [x] 用户能够清除“减少此类”反馈，清除后相关内容恢复正常候选资格。
- [x] 在无网络和没有个人行为历史时，仍能生成可阅读、无重复的推荐顺序。
- [x] 自动化测试覆盖标签偏好、推荐排序、冷启动和数据迁移的关键路径。
- [x] Debug JVM 测试、Android Lint、Debug 构建、数据库/仓库仪器测试与关键 Compose 仪器测试通过。
- [x] `1.8.0 / 10` 版本、发布工作流和 README 保持一致；`app-v1.8.0` 触发的 GitHub App Release 包含签名 APK 和 SHA-256。

## Out of Scope

- 账号体系、跨设备同步和云端用户画像。
- 需要上传个人阅读数据的协同过滤或服务端机器学习。
- 首版不使用本地语义向量、端侧机器学习模型或需要新增模型资产的方案。
- 首版不为内容包增加新的标准推荐分类字段，也不因此批量改写现有 600 张卡片。
