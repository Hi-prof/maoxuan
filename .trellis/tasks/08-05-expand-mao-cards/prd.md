# 扩充毛选卡片内容

## Goal

增加可离线阅读的毛泽东著作卡片，降低当前毛选内容相对其他系列偏少、第四卷覆盖不足的问题，同时保持现有引文、解读、背景和来源质量。

## Confirmed Facts

- 当前正式内容共 600 张：`毛泽东选集` 120 张、`毛泽东诗词` 30 张、`名人名言` 300 张、`马原思考` 150 张。
- 120 张毛选正文覆盖 60 篇；第一至第四卷分别为 32、37、36、15 张，第四卷明显偏少。
- 每张卡片是 `content/cards/` 下独立的 UTF-8 YAML，使用不可复用 UUID，新增卡片从 `revision: 1` 开始。
- 当前正式内容契约要求每张卡片具有来自两个不同域名的至少两个来源；本次用户明确要求改为单来源即可，需要同步调整生产端、消费端、测试和规范，不能只让新增 YAML 绕过校验。
- 用户已确认将内容包升级为 schema 4：正式卡片至少包含一个 `original` 或 `authoritative` 来源，既有双来源卡片保持原样。
- 内容发布是完整快照；新增卡片后必须同步提升内容版本、发布时间、发布说明和 `expectedPublishedCards`，并更新 APK 内置 `bootstrap.zip`。

## Requirements

- 新增 100 张 `毛泽东选集` 正文卡片，不用诗词或其他系列凑数；完成后毛泽东内容共 250 张，正式内容共 700 张。
- 优先补充第四卷和当前尚未覆盖或仅有一张卡片的篇目，同时兼顾实践、调查研究、群众路线、工作方法、团结、建设等主题。
- 每张卡片至少提供一个可访问的原文或权威来源；引文必须能在所列来源中直接核对，篇名、卷次和写作日期保持准确，不收录来源存疑或常见误传语句。
- 解读使用平实中文，说明具体语境、核心含义和适用边界，不把历史语句泛化成脱离条件的口号。
- 背景与故事不得机械复用同一模板；同篇多卡时，每张应从不同论点或语境切入。
- 复用现有已授权背景图，不新增图片资产或许可负担。
- 本次只调整内容源、内容元数据、APK 内置内容及相应数量说明，不改客户端功能、推荐算法或内容架构。
- App 源版本升级为 `1.10.0`（version code 13）；内容升级为 `1.6.0`、`minimumAppVersionCode: 13` 和 schema 4，确保旧版 App 不会下载其无法解析的单来源内容包。

## Acceptance Criteria

- [ ] 新增 100 张卡片，全部为 `published`、`review.status: verified` 的毛选正文卡片；毛泽东内容总数为 250 张，正式卡片总数为 700 张。
- [ ] 新增引文彼此不重复，也不与现有 600 张卡片重复；每条均满足长度、NFC、单段和至少一个可核对来源的规则。
- [ ] 内容生产端和 Android 消费端一致接受一个或多个来源，同时仍拒绝空来源列表、非法 URL 和缺少原文或权威来源的卡片。
- [ ] schema 3 内容包被新版读取器明确拒绝；schema 4 单来源包可成功构建、解析和导入，且不需要 Room schema 迁移。
- [ ] 新增卡片优先改善第四卷和低覆盖篇目的分布，没有依靠单篇密集堆叠完成数量目标。
- [ ] `content/project.yaml` 使用新的 minor 内容版本，声明的正式卡片总数与实际数量一致，发布说明准确概括本次扩充。
- [ ] README 中的内置卡片总数及各系列数量与新内容一致。
- [ ] APK 内置 `app/src/main/assets/bootstrap.zip` 与内容源同步构建。
- [ ] Ruff、内容工具测试、正式内容校验、正式报告和确定性构建全部通过。
- [ ] 新增内容仍需人工复核连续原文、篇名卷次、来源有效性和背景叙述；自动校验结果不替代人工事实审核。

## Out of Scope

- 修改应用界面、数据库结构、推荐逻辑，或改变 schema 4 中除来源下限与版本号之外的字段结构。
- 新增图片、调整既有卡片、下架内容或发布 GitHub Release。

## Decisions

- 新增规模：100 张 `毛泽东选集` 正文卡片。
- 来源规则：schema 4 全局允许单来源，至少一个来源必须为原文或权威类型；既有来源不删减。
- 版本组合：App `1.10.0` / code 13，内容 `1.6.0` / minimum code 13。
