# 星火摘读素材资料

本目录收集适合“星火摘读”后续内容筛选的短句，重点覆盖行动、奋斗、长期主义、面对困难、减少焦虑和停止内耗。

## 文件

- `01-毛泽东著作.md`：24 条，来自《毛泽东选集》及其他可定位到具体讲话、文章的毛泽东著作。
- `02-毛泽东诗词.md`：10 条，侧重逆境、从容、时间感与行动感。
- `03-鲁迅与红色经典.md`：17 条，来自鲁迅、方志敏、李大钊及革命诗作。

合计 51 条候选素材，检索与访问日期为 2026-07-28。

## 核验标记

- `现有正式卡片已核验`：已经进入项目现有正式卡片，并通过当前内容校验规则。
- `来源已定位`：至少有一个能追溯到目标原句或较完整上下文的可靠页面；有更多来源时一并保留，但不作为素材收录的硬性要求。
- `版本待核`：已经找到原句线索，但不同页面存在字词、标点或篇名差异，选作正式卡片前应先确定采用哪个版本。

## 使用边界

1. 这些是研究候选，不会被内容构建工具自动发布。作为素材库，每条有一个可靠、可追溯的来源即可收录。
2. 卡片正文应采用语义完整的连续原文，不拼接、不改写、不用省略号掩盖删节，并控制在 90 个 Unicode code point 以内。
3. “适用”只是编辑方向，不是作者原意的替代解释。正式解读必须回到原文上下文。
4. 这里只保存少量短引和来源链接，不镜像全文。公开发布前仍需复核著作权、引用边界和具体版本；本说明不构成法律意见。
5. 当前 `content/` 正式内容校验器仍要求至少两个独立来源；若以后直接导入正式卡片，需要按当时的产品规则补来源或先调整内容契约。这不影响本资料库收录和使用。
6. 网络上常见的“如果你觉得累就停下来”“不要精神内耗”等现代改写，没有可靠原始出处，本次没有冒充毛泽东或鲁迅原话收录。

## 推荐筛选顺序

1. 先从 `现有正式卡片已核验` 和 `来源已定位` 中选语义完整、90 字以内的句子。
2. 打开来源阅读全文，确认截取位置和上下文没有改变原意。
3. 再编写“核心意思、理解重点、现实启示”，不要把现代心理学概念强行写成作者原意。
4. 最后按 `content/templates/card.yaml` 建正式卡片，并运行内容校验。
